# OpenFeed Stable Core Policy

Status: Stable Core

Version: 1.x

## Purpose

OpenFeed is the content acquisition layer of the Yasin ecosystem.

## Allowed Changes

- Bug fixes
- Performance improvements
- Security patches
- Dependency updates
- Compatibility fixes

## Not Allowed

- AI features
- Publishing logic
- Scheduling
- Dashboard
- Plugin system
- Business logic

These features belong to FeedBridge.
